Before you start

The stack

Seven tools. You talk to one of them, Claude Code, and it uses the rest. You will not write code by hand.

ToolWhat it doesCost
VS CodeThe app your project lives in. You watch every file Claude Code creates or changes.Free
Claude CodeThe AI agent that writes, runs and checks the video code. You direct it in plain English.Needs a Claude Pro plan or higher. The free plan does not include it.
Node.jsRuns Remotion on your laptop.Free
GitSaves versions of your project, so a bad change can be undone.Free
FFmpegVideo toolbox: turns renders into MP4s, cuts reference videos into stills, measures loudness.Free
RemotionMakes videos out of code. Every frame is a web page, so animated product screens come naturally.Free for individuals and companies of up to three people. Bigger companies need a licence.
ElevenLabsMusic, voice-over and sound effects, connected to Claude Code. Optional.Free plan to start. Paid plans from $6 a month.

What you need first

  • A laptop, Mac or Windows, with at least 8 GB of memory and about 10 GB free. Video renders are heavy; a phone or tablet will not do it.
  • A Claude Pro account at claude.ai. Sign up before you start.
  • A decent connection and about an hour. Installs download a few hundred MB.
The one rule. When something fails, copy the exact message you see and paste it to Claude Code with "this happened, fix it". Most setup problems are one message away from solved.

01
Step one

VS Code and Claude Code

Install VS Code

  1. Download VS Code from code.visualstudio.com and install it.
  2. Make a folder called videos in your Documents folder.
  3. In VS Code, choose File, then Open Folder, and pick videos. If it asks whether you trust the folder, say yes.

Add Claude Code

  1. Open Extensions: Cmd+Shift+X on a Mac, Ctrl+Shift+X on Windows.
  2. Search for Claude Code, check the publisher is Anthropic, and click Install.
  3. Click the Claude Code icon (a small spark) in the bar on the left, then Sign in with your Claude Pro account.
Test it

Create a file called hello.md that says hello, then tell me what you did.

Claude Code shows you the file before saving it and asks permission. Click accept. That is the pattern for everything that follows: you ask, it proposes, you approve.

The terminal, for the few commands in this guide

In VS Code choose Terminal, then New Terminal. It opens at the bottom, already inside your videos folder. Type a command and press Enter.

Step two

Node.js, Git and FFmpeg

Node.js

Download the version marked LTS from nodejs.org and install it with the default options. Close VS Code, open it again, and check it in the terminal:

node --version

A number starting with v means it worked.

Git

Mac

Type this. If a box asks to install developer tools, click Install.

git --version

Windows

Install Git for Windows from git-scm.com with the default options, then restart VS Code.

FFmpeg

Mac

With Homebrew (from brew.sh) installed:

brew install ffmpeg

Windows

In the terminal:

winget install --id Gyan.FFmpeg

Restart VS Code, then check:

ffmpeg -version
Or let Claude Code do it

Check this laptop has Node.js, Git and FFmpeg. Tell me what is missing and install it, asking me before anything that needs my password.

03
Step three

Your first video project

Create the Remotion project

In the terminal, inside your videos folder:

npx create-video@latest my-first-video

Pick the Blank template and say yes to TypeScript if asked. Then open the new my-first-video folder in VS Code with File, then Open Folder.

Give Claude Code the Remotion plugin

The plugin teaches Claude Code how Remotion works, so it writes the video properly instead of guessing.

  1. In the Claude Code panel, type /plugins to open Manage plugins.
  2. On the Marketplaces tab, add remotion-dev/claude-code-plugin.
  3. On the Plugins tab, search for remotion, click Install, and choose Install for you.
  4. Close VS Code and open it again so the plugin loads.
Prefer no licence to think about? HyperFrames does the same job from plain HTML and CSS, free for any company size. Add the marketplace heygen-com/hyperframes instead and install hyperframes. Everything else in this guide stays the same.

Let Claude Code see its own work

Set up the project

Set this Remotion project up for a [30]-second video at 1920 by 1080, 30 frames a second. Start Remotion Studio so I can watch it in my browser. Then write a small helper that renders any frames I name as still images and tiles them into one contact sheet, so you can check your own work after every change.

The contact sheet is how the agent "sees". Without it, it is guessing what the video looks like.

04
Step four · optional

Music and voice with ElevenLabs

Skip this until your first video works without sound. When you want music, a voice-over or sound effects, connect ElevenLabs to Claude Code.

1. Get an API key

Sign up at elevenlabs.io, open your profile's API Keys page, and create a key. Treat it like a password: never in a screenshot, a chat or a file you share.

2. Install uv, the helper the connector runs on

Mac

brew install uv

Windows

winget install --id astral-sh.uv

3. Add the ElevenLabs connector

In the terminal, inside your project folder, paste your key where it says your_key:

claude mcp add elevenlabs -e ELEVENLABS_API_KEY=your_key -- uvx elevenlabs-mcp

Restart VS Code. In Claude Code, type /mcp and check elevenlabs is listed as connected.

Test it

Use ElevenLabs to make a 10-second upbeat instrumental and save it in a folder called audio. Tell me how many credits it used.

Credits. Music and voice use your ElevenLabs credits. Ask Claude Code to tell you the cost before anything long, and keep tests short.

Before your first video

Check it all works

The first render

Make a 5-second test video: our name [your name] builds in word by word on a blue background, then a white check mark draws itself. Show me a contact sheet of every 10th frame, then render it to an MP4 in a folder called out.

  • VS Code opens your project and Claude Code answers you
  • node --version, git --version and ffmpeg -version all print a version
  • Remotion Studio opens in your browser and plays the test video
  • Claude Code can render a contact sheet and you can open it
  • An MP4 appears in the out folder and plays on your phone
  • (Optional) /mcp shows ElevenLabs connected

When something goes wrong

You seeDo this
"command not found"Close and reopen VS Code so it picks up the new install, then try again.
Claude Code will not sign inCheck your Claude plan is Pro or higher. The free plan does not include Claude Code.
Render fails with a disk errorAsk Claude Code to delete old render folders, and render previews as JPEG stills.
Anything elsePaste the exact error to Claude Code and ask it to fix it.
